## 🚚 Apartment Delivery Ecosystem (Capstone Project)
An optimized delivery system for high-rise apartment complexes featuring a specialized Route Optimization Algorithm.

## 📖 Overview
This ecosystem provides an end-to-end solution for ordering and delivery services within complex apartment environments. It consists of 4 integrated applications:

  - User App: For residents to browse stores and place orders.
  - Store App: For merchants to manage products and incoming orders.
  - Shipper App: For delivery personnel with real-time tracking.
  - Admin Dashboard: For system-wide management and monitoring.

## 🚀 Key Features & Engineering Challenges
1. Delivery Route Optimization:
  - Problem: High-rise buildings present unique logistics challenges with vertical travel and dense delivery points.
  - Solution: Designed and optimized a specialized Delivery Algorithm to minimize travel distance and ensure efficient distribution.

2. Real-time Synchronization:
  - Implemented seamless data synchronization between 4 different applications to ensure order status is always up-to-date.
  - Integrated Firebase Cloud Messaging for secure, real-time push notifications and automated messaging.

3. Automated CI/CD Pipeline
  - Built automated pipelines for both Front-end and Back-end to streamline deployment and ensure continuous integration.

## 🛠 Technical Stack
  - Frontend: ReactJS, Flutter (Mobile).

  - Backend: NodeJS, RESTful APIs, Web API, Entity Framework.

  - Database: MS SQL Server, Firebase (Real-time Database & Image Storage).

  - DevOps: GitHub, CI/CD Pipeline.
